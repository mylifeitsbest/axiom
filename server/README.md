# Axiom — сервер статистики

Тихий счётчик: браузер раз в час шлёт на этот сервер несколько байт (версия,
система, флаги «первый запуск за день/неделю/месяц», «новая установка»). Хранятся
только суммы — ни IP, ни идентификаторов. Панель показывает DAU/WAU/MAU,
установки и разбивку по версиям и системам.

## Установка (Ubuntu 24.04, от root)

Скопировать папку на сервер и запустить установщик:

```
scp -r server root@IP:/root/axiom-stats
ssh root@IP
cd /root/axiom-stats && sudo bash deploy.sh
```

`deploy.sh` ставит Python-службу (`axiom-stats.service`) и Caddy для HTTPS,
создаёт секретный ключ панели и печатает её адрес. Повторный запуск ничего не
ломает — ключ и база сохраняются.

Адрес панели секретный (ключ прямо в ссылке) — никому не давать. База лежит в
`/var/lib/axiom-stats/stats.db`.

## Проверка

```
systemctl status axiom-stats caddy
curl https://ДОМЕН/health        # -> ok
journalctl -u axiom-stats -n 50
```

Домен по умолчанию — `179-254-172-240.sslip.io` (sslip.io превращает IP сервера
в имя, на которое Let's Encrypt выдаёт сертификат; отдельный домен не нужен).
Сменить: `sudo AXIOM_STATS_DOMAIN=example.com bash deploy.sh` — но тогда тот же
адрес нужно прописать в `STATS_URL` в `src/stats.rs` и выпустить новую версию
браузера.
