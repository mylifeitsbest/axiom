# Axiom — сервер статистики

Тихий счётчик: браузер раз в час шлёт на этот сервер несколько байт (версия,
система, флаги «первый запуск за день/неделю/месяц», «новая установка»). Хранятся
только суммы — ни IP, ни идентификаторов. Панель показывает DAU/WAU/MAU,
установки и разбивку по версиям и системам.

## Установка (Ubuntu 24.04, от root)

Скопировать папку на сервер и запустить установщик:

```
scp -r server root@IP:/root/axiom-stats
ssh root@IP
cd /root/axiom-stats && sudo bash deploy.sh
```

`deploy.sh` ставит Python-службу (`axiom-stats.service`) и Caddy для HTTPS,
создаёт секретный ключ панели и печатает её адрес. Повторный запуск ничего не
ломает — ключ и база сохраняются.

Адрес панели секретный (ключ прямо в ссылке) — никому не давать. База лежит в
`/var/lib/axiom-stats/stats.db`.

## Отчёты об ошибках

Кроме пингов, браузер шлёт сюда отчёты (`POST /r`, JSON до 64 КБ):

```
{"kind": "crash" | "renderer" | "user", "version": "0.5.4", "os": "windows",
 "text": "что случилось", "log": "конец журнала axiom.log"}
```

`crash` — вылет (паника, жёсткое завершение, ошибка запуска), `renderer` — упал
процесс страницы, интерфейса или GPU, `user` — «Сообщить о проблеме» в настройках.
Адреса страниц, пути с именем пользователя, почту и токены браузер вычищает ещё до
отправки. Хранятся 90 дней, не больше 2000 штук, без IP. На панели — раздел
«Отчёты», каждый отчёт целиком — по ссылке `/d/<ключ>/r/<номер>`.

### Ответ человеку

У сообщения из «Сообщить о проблеме» есть случайный ключ ответа (`"token"`,
32 шестнадцатеричных знака) — с браузером и другими сообщениями он не связан.
На странице такого отчёта есть форма «Ответ человеку»: «Исправлено» или «Ответ»,
версия, где исправлено (можно пусто), и текст. То же без браузера:

```
curl -X POST https://ДОМЕН/d/<ключ>/r/<номер> --data-urlencode s=fixed   --data-urlencode v=0.6.1-beta.150 --data-urlencode "text=Исправили, спасибо!"
```

(`s=reply` — просто ответ, `do=clear` — убрать ответ.) Браузер, пока открыт, раз
в 20 минут спрашивает `POST /a {"t": [ключи]}` и показывает ответ кнопкой «Вам
ответили»; в списке отчётов видно «ждёт ответа», «исправлено» и «✓», когда браузер
ответ забрал. На отчёты из Axiom без ключа (до этой версии) ответить нельзя.

С одного IP принимается не больше 30 пингов, 20 отчётов и 120 вопросов об ответах в час (за Caddy адрес
берётся из `X-Forwarded-For`, его ставит сам Caddy).

Обновить только сборщик (база и ключ сохраняются, таблица отчётов создаётся при
запуске):

```
ssh root@IP 'mkdir -p /root/axiom-stats'
scp server/* root@IP:/root/axiom-stats/
ssh root@IP 'cd /root/axiom-stats && bash deploy.sh'
```

или вручную: `stats.py` → `/opt/axiom-stats/stats.py`, Caddyfile с подставленным
доменом → `/etc/caddy/Caddyfile`, затем `systemctl restart axiom-stats` и
`systemctl reload caddy`. Caddyfile менять обязательно: без него Caddy не пропустит
отчёт длиннее 4 КБ и длинный ответ человеку.

Тесты: `python3 -m unittest discover -s server -v`.

## Проверка

```
systemctl status axiom-stats caddy
curl https://ДОМЕН/health        # -> ok
journalctl -u axiom-stats -n 50
```

Домен по умолчанию — `179-254-172-240.sslip.io` (sslip.io превращает IP сервера
в имя, на которое Let's Encrypt выдаёт сертификат; отдельный домен не нужен).
Сменить: `sudo AXIOM_STATS_DOMAIN=example.com bash deploy.sh` — но тогда тот же
адрес нужно прописать в `STATS_URL` в `src/stats.rs` и выпустить новую версию
браузера.
