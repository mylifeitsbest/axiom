# Плагины Axiom

Плагин — это папка со скриптами и стилями, которые Axiom запускает на нужных вам
сайтах. Плагин может поменять страницу, добавить на неё что угодно, спрятать лишнее,
сохранить свои данные, показать сообщение и открыть вкладку. Написать его можно за
пять минут: нужен только текстовый редактор и немного JavaScript.

## Как это устроено

- Плагины лежат в папке профиля Axiom, в `plugins/`: каждый плагин — своя папка.
  Где эта папка, показано в **Настройки → Плагины**, кнопка **Открыть** открывает её.
- Новый плагин в папке сам не включается. Его включают переключателем в его карточке
  в **Настройки → Плагины**: там же видно, на каких сайтах он работает и что ему можно.
- Скрипты плагина выполняются во вкладках, в **изолированном мире**. DOM страницы у
  плагина и сайта общий: плагин видит и меняет страницу. А переменные JavaScript у
  каждого свои: сайт не видит ни кода плагина, ни объекта `axiom` и не может ими
  воспользоваться. Так же работают скрипты расширений в Chrome.
- Включённый плагин начинает работать на страницах, которые открыли или обновили
  после включения. Выключенный — пропадает со страницы после её обновления.
- Поменяли файлы плагина — нажмите **Обновить** в **Настройки → Плагины** и обновите
  страницу.

Работает на Windows (WebView2) и Linux (WebKitGTK).

## Первый плагин

Создайте в папке плагинов папку `hello` и в ней два файла.

`plugin.json`:

```json
{
  "api": 1,
  "id": "hello",
  "name": "Привет",
  "version": "1.0.0",
  "permissions": ["notify"],
  "content_scripts": [
    { "matches": ["<all_urls>"], "js": ["content.js"] }
  ],
  "action": { "title": "Сказать привет" }
}
```

`content.js`:

```js
axiom.on('action', () => {
  axiom.notify(`Привет со страницы «${document.title}»`);
});
```

Нажмите **Обновить** в **Настройки → Плагины**, включите «Привет» и обновите любую
страницу. На панели рядом с кнопкой ИИ появится кнопка плагина: нажмите её — внизу
окна появится сообщение.

## plugin.json

| Поле | Обязательно | Что это |
|---|---|---|
| `api` | да | Версия API плагинов. Сейчас `1`. Плагин с большей версией попросит обновить Axiom |
| `id` | да | Имя плагина латиницей: от 2 до 40 знаков, строчные буквы, цифры и `-`. Своё у каждого плагина: данные плагина хранятся по нему |
| `name` | да | Название, до 60 знаков |
| `version` | да | Версия, например `1.0.0` |
| `description` | | Что делает плагин, до 400 знаков |
| `author` | | Автор, до 100 знаков |
| `homepage` | | Страница плагина (`https://…`): кнопка «Страница плагина» в его карточке |
| `icon` | | Значок: путь к картинке в папке плагина (`png`, `svg`, `webp`, `jpg`, `gif`, `ico`, до 128 КБ) |
| `permissions` | | Что плагину можно сверх своих страниц: `notify`, `tabs` (см. [API](#api-объект-axiom)) |
| `content_scripts` | да | Скрипты и стили: где и когда их запускать (ниже) |
| `action` | | Кнопка на панели браузера: `{ "title": "Подсказка", "icon": "button.svg" }`. Без `icon` — значок плагина или первая буква названия |
| `settings` | | Настройки плагина в его карточке (см. [Настройки плагина](#настройки-плагина)) |

Каждая запись `content_scripts`:

| Поле | Что это |
|---|---|
| `matches` | На каких страницах запускать: список [шаблонов адресов](#шаблоны-адресов) |
| `exclude` | На каких из них не запускать (можно и `exclude_matches`, как в Chrome) |
| `js` | Скрипты, по порядку. Файлы одной записи склеиваются и выполняются как один скрипт: их переменные общие |
| `css` | Стили (см. [Стили](#стили)) |
| `run_at` | Когда запускать скрипты: `start` — до скриптов сайта, страницы ещё нет (`document.documentElement` пуст); `ready` (по умолчанию) — разметка готова (`DOMContentLoaded`); `load` — страница загрузилась целиком. Названия из Chrome (`document_start`, `document_end`, `document_idle`) тоже подходят |
| `all_frames` | `true` — запускать и во фреймах страницы, не только в ней самой. Во фреймах работает только DOM: API `axiom.*` там отвечает ошибкой |

Файлы — пути внутри папки плагина через `/`, без `..`. Один файл — до 2 МБ, весь код
и стили плагина — до 5 МБ, текст в UTF-8.

Ошибку в `plugin.json` Axiom показывает в **Настройки → Плагины**: с местом в файле и
тем, что именно не так. Такой плагин не запускается.

## Шаблоны адресов

| Шаблон | Где работает |
|---|---|
| `<all_urls>` или `*` | Все страницы `http` и `https` |
| `youtube.com` или `*.youtube.com` | Сайт и все его поддомены (`www.`, `m.`…), любая страница |
| `https://*.example.com/watch*` | Полная запись: схема (`http`, `https` или `*` — обе), хост (`*` — любой, `*.сайт` — сайт с поддоменами, `сайт` — ровно он) и путь со `*` |
| `*://example.com/*` | Только `example.com`, без поддоменов |
| `http://localhost/*` | Порт не важен: и `localhost:3000`, и `localhost:5173` |

Путь сравнивается вместе со строкой запроса: `https://*/*.pdf` не подойдёт к
`https://a.b/file.pdf?x=1`, а `https://*/*.pdf*` подойдёт. Кириллический домен
сравнивается так, как его видит браузер (в punycode), это Axiom делает сам.

Страницы самого Axiom (новая вкладка, настройки, история), `file:` и `data:`
плагинам недоступны.

## API: объект axiom

Объект `axiom` — глобальный в мире плагина. Всё, что ходит в браузер, возвращает
`Promise`; ошибка (нет разрешения, слишком большое значение…) приходит как `Error` с
понятным текстом.

### axiom.plugin

`{ id, name, version }` — сведения о самом плагине из `plugin.json`.

### axiom.settings

Значения настроек плагина: `{ ключ: значение }`. Всегда полный набор — что человек не
менял, то по умолчанию. При смене настроек объект заменяется новым (см. `axiom.on`).

### axiom.storage

Хранилище плагина: ключи и значения JSON. Своё у каждого плагина, общее для всех
сайтов, переживает перезапуск Axiom. Разрешение не нужно. Всего до 1 МБ.

```js
await axiom.storage.set('count', 5);              // один ключ
await axiom.storage.set({ a: 1, b: [1, 2] });     // несколько сразу
await axiom.storage.get('count');                 // → 5 (нет ключа — undefined)
await axiom.storage.get(['a', 'b']);              // → { a: 1, b: [1, 2] }
await axiom.storage.get();                        // → всё хранилище
await axiom.storage.remove('a');                  // или remove(['a', 'b'])
await axiom.storage.clear();
```

Удалили плагин — удалилось и его хранилище.

### axiom.notify(text)

Сообщение внизу окна Axiom: «Название плагина: текст». До 300 знаков, не чаще трёх
сообщений за 5 секунд. Разрешение `notify`.

### axiom.tabs.open(url, { background })

Открывает адрес `http`/`https` в новой вкладке рядом с этой. Относительный адрес
считается от адреса страницы. `{ background: true }` — не переходить на новую вкладку.
Не больше пяти вкладок за 10 секунд. Разрешение `tabs`.

### axiom.on(event, fn) и axiom.off(event, fn)

- `'action'` — нажали кнопку плагина на панели (нужно поле `action` в `plugin.json`).
  Событие получает плагин на странице активной вкладки. Если на ней плагин не
  работает (адрес не подходит) или не подписан на `action`, Axiom скажет: «Плагин не
  работает на этой странице».
- `'settings'` — поменяли настройки плагина. `fn(settings)` получает новые значения,
  страницу обновлять не нужно.

```js
axiom.on('settings', (s) => {
  document.documentElement.classList.toggle('my-plugin-big', s.big);
});
```

API работает в самой странице. Во фреймах (`all_frames`) вызовы отвечают ошибкой.

## Стили

Стили из `css` применяются ко всей странице с самого начала её загрузки, ещё до
скриптов сайта, — и на сайтах со строгой политикой CSP, где вставленный `<style>` не
сработал бы (Axiom добавляет их через `document.adoptedStyleSheets`). `@import` в них
не работает.

Стили, которые зависят от настроек, удобно включать атрибутом или классом на `<html>`
(см. пример «Тихий YouTube»).

## Настройки плагина

Поле `settings` — список настроек. Axiom рисует их в карточке плагина, хранит и отдаёт
плагину в `axiom.settings`.

```json
"settings": [
  { "key": "big", "type": "toggle", "label": "Крупный текст", "default": false },
  { "key": "name", "type": "text", "label": "Ваше имя", "placeholder": "Аня", "max_length": 40 },
  { "key": "speed", "type": "number", "label": "Скорость", "note": "Слов в минуту", "default": 200, "min": 50, "max": 1000, "step": 10 },
  { "key": "mode", "type": "choice", "label": "Режим", "default": "soft",
    "options": [{ "value": "soft", "label": "Мягкий" }, { "value": "hard", "label": "Жёсткий" }] }
]
```

| Поле | Что это |
|---|---|
| `key` | Имя значения в `axiom.settings`: латиница, цифры и `_`, до 40 знаков |
| `type` | `toggle` (вкл/выкл), `text` (строка), `number` (число), `choice` (один из вариантов) |
| `label` | Название настройки, до 80 знаков |
| `note` | Подсказка под названием, до 300 знаков |
| `default` | Значение по умолчанию. Не подходит типу — `false`, `""`, ближайшее к нулю число в границах или первый вариант |
| `options` | Для `choice`: от 1 до 30 вариантов `{ value, label }`. До трёх — кнопками, больше — списком |
| `min`, `max`, `step` | Для `number` |
| `max_length`, `placeholder` | Для `text`: длина (по умолчанию до 1000) и подсказка в пустом поле |

Не подходящее полю значение Axiom не сохранит.

## Отладка

- Ошибки в скриптах плагина видны в консоли инструментов разработчика вкладки (F12),
  с названием плагина в начале. Код плагина там называется `axiom-plugin/<id>.js`.
- Чтобы выполнять команды в мире плагина, выберите в консоли вместо `top` контекст
  `Axiom plugin: <id>`.
- Поменяли файлы — **Обновить** в **Настройки → Плагины**, затем обновите страницу.

## Безопасность и ограничения

- Плагин видит и меняет страницы, на которых работает, — как расширение в Chrome.
  Ставьте только плагины, которым доверяете, и смотрите в карточке, на каких сайтах
  он работает и что ему можно.
- Плагин не может вызывать команды браузера, кроме своего API. Разрешения проверяет
  сам Axiom, а не страница: без `notify` и `tabs` сообщения и вкладки не получатся,
  даже если плагин попробует обойти `axiom.*`.
- Сайт не может притвориться плагином: функции-мосты есть только в мире плагина.
- Каждый плагин живёт в своём мире и не видит переменных других плагинов. Хранилище
  тоже у каждого своё.
- Плагины не запускаются в панели ИИ и на страницах самого Axiom.
- Пока нет: фоновых скриптов (плагин работает только вместе со страницей), своих
  окошек у кнопки на панели, сетевых запросов в обход CORS, доступа к истории и
  закладкам. Это следующие версии API: старые плагины с `"api": 1` продолжат работать.

## Примеры

В репозитории, в [`examples/plugins`](../examples/plugins):

- [`hello`](../examples/plugins/hello) — кнопка на панели считает слова на странице и
  время чтения; настройки (число и переключатель), хранилище, сообщение.
- [`quiet-youtube`](../examples/plugins/quiet-youtube) — прячет Shorts и комментарии на

Чтобы попробовать, скопируйте папку примера в папку плагинов, нажмите **Обновить** и
включите плагин.
