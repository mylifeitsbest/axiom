# Магазин плагинов Axiom — сайт и каталог

Отдельная служба на том же сервере, что и статистика, но **ничем с ней не связанная**:
свой процесс (`axiom-store.service`), своя база (`/var/lib/axiom-store/store.db`), свой
адрес (`https://plugins.179-254-172-240.sslip.io`) и свой ключ администратора
(`/etc/axiom-store.env`). Общий у них только Caddy, который раздаёт HTTPS обоим.

- Браузер берёт отсюда каталог (`/api/index`) и плагины (`/api/p/<id>`) — магазин в
  «Настройки → Плагины».
- Разработчики на сайте подают заявку, получают личный ключ, входят по нему и
  загружают плагины. В каталог плагин попадает только после проверки.
- Ключ администратора открывает всё: заявки, разработчики (новый ключ, отозвать),
  проверка плагинов с их кодом, снять или вернуть плагин. Свои плагины администратор
  загружает без проверки — они публикуются сразу, с пометкой «Axiom».
- Плагины Axiom из `store/plugins` публикуются при каждом запуске службы.

## Установка и обновление

На сервере, из клона репозитория (или из папки, куда скопированы `store/server` и
`store/plugins`), от root:

```sh
bash store/server/deploy.sh
```

Скрипт ставит `store.py`, плагины Axiom, службу и сайт в Caddy
(`/etc/caddy/sites/axiom-store.caddy`, основной `Caddyfile` подключает эту папку),
проверяет конфиг Caddy и в конце печатает адрес сайта и **ключ администратора**. Ключ
создаётся один раз; посмотреть его потом: `cat /etc/axiom-store.env`.

Повторный запуск безопасен: база и ключ сохраняются.

## Как одобрить разработчика

1. Войти на сайте по ключу администратора → «Заявки».
2. «Одобрить и выдать ключ» — ключ появится на странице «Разработчики» (пока человек
   его не забрал) и по секретной ссылке, которую он получил при заявке.
3. Если человек потерял ключ — «Новый ключ»: прежний перестанет работать сразу.

## Проверка

`python -m unittest discover -s store/server -v` из корня репозитория. Локально:

```sh
AXIOM_STORE_DB=/tmp/store.db AXIOM_STORE_PORT=18788 AXIOM_STORE_INSECURE=1 \
AXIOM_STORE_ADMIN_KEY=axa_local_admin_key_for_tests AXIOM_STORE_OFFICIAL=store/plugins \
python3 store/server/store.py
```

и debug-сборка Axiom с `AXIOM_STORE_URL=http://127.0.0.1:18788`.
